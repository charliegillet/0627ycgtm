## Valid bridges (share ≥3 of: same buyer / same event stream / same artifact / adjacent workflow steps / same metric)

**Bridge B1 — "Evidence-backed selling" (Sales Cyborgs × Reading Minds × Revenue Autopilot)**
Same buyer (RevOps/AE), same event stream (a live sales conversation), same artifact (a verified claim/evidence card), same metric (deal advancement). Conversation → extract verifiable buyer needs/objections → retrieve grounded proof (Moss) → act (write-back to CRM + route follow-up) → measure deal movement. Hits P1,P2,P3,P5. **Voice-native** (LiveKit/Nova).

**Bridge B2 — "Provenance content engine" (Ad Factories × Algorithm Hacking × Reading Minds)**
Same buyer (content/growth marketer), same artifact (a content asset with cited sources), same metric (AI-search citation share). Customer-conversation/community signal → generate asset with visible provenance (counters P4 trust collapse) → publish optimized for AI citation (P9) → measure citation/referred sessions → learn. Trust-as-wedge.

**Bridge B3 — "Onboarding value autopilot" (Sales Cyborgs/CS × Revenue Autopilot × Reading Minds)**
Same buyer (PLG product/growth), same event stream (product usage), same artifact (a value-proof / activation milestone), same metric (activation rate / TTFV). Usage → detect stalled user before value (P7) → act (voice/in-app guide + write-back) → measure activation → expansion trigger (P8). Voice-native onboarding concierge.

**Bridge B4 — "Honest ROI / incrementality loop" (Revenue Autopilot × Reading Minds × Algorithm Hacking)**
Same buyer (CMO/RevOps), same artifact (an incrementality verdict), same metric (incremental revenue, not vanity). Multi-system signal → decide what actually drove revenue (P5,P10) → act (reallocate/flag) → measure incremental lift honestly → learn. Counters P10 ROI gap. (Risk: incrementality needs real traffic — time-scale fatal-flaw watch.)

**Bridge B5 — "Live deal-desk concierge" (Sales Cyborgs × Revenue Autopilot × Reading Minds)**
Same buyer (AE + buyer on a call), same event stream (a pricing/negotiation call), same artifact (a quote/term sheet), same metric (close + correct price). Voice call → detect buyer constraints → retrieve approved pricing/terms (Moss) → act (generate quote, write-back, route approval P8) → measure close → learn pricing priors.

## Rejected (track-salad — no shared event/artifact)
- "Dashboard that shows ads + SDR + onboarding + billing in one UI" — features aggregated, no single event flows through. REJECT.
- "AI that does cold email + GEO + dialer" — three unrelated buyers/metrics. REJECT.

## Note for ideation
Sponsor center-of-gravity is **conversational/voice** (Moss semantic retrieval + LiveKit/Nova/MiniMax voice). Bridges B1, B3, B5 are voice-native and should be weighted up. Trust/provenance (B2) and honest-incrementality (B4) are strong wedges but B4 risks the time-scale fatal flaw.
