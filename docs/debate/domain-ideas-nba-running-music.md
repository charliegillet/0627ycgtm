## Running / endurance / fitness

### Winner: ClubRadar  (EV 0.7 | top-3 60 / Convex 80 / genuine-use 70)
*Point it at a city. Get a ranked, scored, ready-to-send pipeline of the run clubs your brand should sponsor this quarter, before your competitor does.*

ClubRadar is a DETECT->ENRICH->SCORE->ACT engine sold to the grassroots/field-marketing and partnerships teams at DTC endurance brands (On, Hoka, Tracksmith, Nobull, Saysh) and specialty retail (Fleet Feet, Marathon Sports). Run clubs are the single hottest, lowest-CAC growth channel in fitness right now: Strava run clubs nearly quadrupled to ~1M in 2025 and brands are visibly reallocating ad budget into hyper-local club sponsorships. But the partnerships teams find clubs by Instagram-stalking and a messy spreadsheet. ClubRadar turns 'which clubs should we put product and money behind' into a live, scored, explainable pipeline: it discovers real, active run clubs in a metro from public footprints (Instagram, Eventbrite/luma/Partiful events, RunSignup, race results, club websites), enriches each (followers + growth slope, weekly event cadence, attendance proxies, geo, vibe/ICP fit, and an 'is-this-club-currently-unsponsored' inference), scores them on REACH x MOMENTUM x BRAND-FIT x WHITESPACE (unsponsored), and drafts the exact ambassador/seeding outreach with a recommended gear allocation and a one-line whitespace rationale. The merged-and-upgraded form of ClubScout (#6) + ClubRadar (#11), with Sponsor Whitespace (#13) folded in as the WHITESPACE score dimension rather than a fragile standalone.

- **Signal:** A composite, hard-to-buy 'rising unsponsored run club' signal built ENTIRELY from non-Strava public data (this is deliberate, see risks): (1) MOMENTUM = Instagram follower-growth slope + posting cadence + recurring-event frequency on Eventbrite/luma/Partiful/RunSignup (growth slope and cadence, NOT raw size: a 60-person club growing 15%/mo with weekly runs beats a stale 3k-follower club); (2) REACH = audience size x estimated attendance; (3) BRAND-FIT = LLM read of the club's content/vibe/discipline (road vs trail vs social-pace vs competitive) against the brand's ICP; (4) WHITESPACE = an inferred 'currently unsponsored in your category' flag from absence of @brand kit tags / sponsor mentions / link-in-bio affiliates. No data vendor sells a ranked, brand-fit-scored, unsponsored-club list. The double signal of 'getting big fast AND not yet locked up by a competitor' is the genuinely novel join.
- **DETECT:** Seed from public metro footprints: Instagram run-club accounts, Eventbrite/luma/Partiful event listings tagged running, RunSignup club/race pages, race-results org clusters, and club websites. Fiber AI for company/people enrichment and reverse lookups where available; a cached, hand-verified snapshot of 2 dense metros (e.g. NYC + Austin or SF) as the locked happy path. Convex cron/HTTP actions poll the live sources during the demo so a couple of cards genuinely stream in fresh.
- **ENRICH:** Convex Workpool fans out per-club enrichment in parallel: pull follower counts + recent-post timestamps to compute growth slope and cadence; count events over trailing weeks; estimate attendance from RSVP/photo signals; LLM-classify discipline/vibe for brand-fit; scan bio/posts/kit for sponsor tags to set the whitespace flag. Each enrichment writes back reactively so the board re-ranks live. A coverage meter climbs as enrichment lands.
- **SCORE:** Transparent weighted score = REACH x MOMENTUM x BRAND-FIT x WHITESPACE, each sub-score shown with the evidence that produced it and a confidence. Crucially, the engine ABSTAINS: clubs with thin/ambiguous data are flagged 'needs human verify' rather than scored falsely, and the whitespace flag is always presented as a scored guess-with-reasons ('no apparel tags seen in last 20 posts'), never a hard claim. This abstention + show-your-work directly flatters the rigor judges (Danilo) and dodges the 'made-up number' trap.
- **ACT:** Agent component drafts the actual ambassador/seeding outreach per club (personalized to the club's vibe and recent activity), plus a recommended gear-allocation (e.g. '24 pairs seeded across the Tuesday crew') and a one-line whitespace rationale the rep can paste. Persistent Text Streaming streams the brief/outreach writing live. AutoSend queues it. The ACT is firmly B2B (offer to sponsor a CLUB), never DMing individual runners, which keeps it clear of the AI-SDR/spam backlash.
- **Stack:** Convex (reactive DB, cron, HTTP actions, Workpool for enrichment fan-out, Agent component for drafting, Persistent Text Streaming for live brief, AutoSend to queue) as the core; Fiber AI for people/company enrichment + reverse-email; OpenAI structured outputs for the brand-fit classification and scoring rationale; Next.js/React front end with a live re-ranking leaderboard + metro map view. Public sources: Instagram, Eventbrite, luma, Partiful, RunSignup, race-results pages, club sites. Explicitly NO Strava API (ToS now bans AI use of its data).
- **Convex angle:** This is a near-perfect Convex showcase and a strong $1k-track entry: the reactive DB IS the demo. Clubs stream in as cold cards, Workpool fans out enrichment in parallel, and the leaderboard physically re-ranks in real time as scores land, with a coverage meter climbing and the outreach brief streaming token-by-token via Persistent Text Streaming. Cron + HTTP actions pull a few live cards mid-demo. It uses 4-5 distinct Convex components doing real work, not decoration.
- **Demo plan:** 0-30s WOW: 'On's field-marketing team wants to own NYC run clubs this quarter.' Type 'New York City', hit Scan. Cold cards flood in and the leaderboard starts re-ranking live as enrichment lands, coverage meter climbing. 30-75s: zoom on the #1 club, show the explainable score (REACH/MOMENTUM/BRAND-FIT/WHITESPACE each with evidence + confidence), and point at a club the engine ABSTAINED on ('thin data, verify manually') to prove rigor. 75-150s: click 'Draft play' on the top unsponsored, fast-growing club; the personalized ambassador outreach + gear-allocation rec streams live via Persistent Text Streaming. 150-180s: a live cron-pulled card streams in fresh and slots into the ranking on screen ('this just updated'), then a counter: 'X on-ICP, unsponsored, high-momentum clubs surfaced in 90 seconds vs a week of IG-stalking.' Make a judge's brand the protagonist if one fits. Lock 2 cached metros as the happy path; the live pull is the garnish, not the dependency.
- **Target judges:** Vincent (tool a growth team runs Monday) + Vihaar (custom hard-to-buy signal) are the primary targets; the abstention/show-your-work satisfies Danilo's rigor lens; the live re-ranking board + map covers Coolness.
- **21h scope:** Tight and achievable. Hour 0-4: Convex schema + ingest 2 cached metros of real club data (the bulk of the data-eng work, done up front and verified). 4-9: Workpool enrichment + scoring model + abstention. 9-13: live re-ranking leaderboard UI + map + explainable score cards. 13-17: Agent draft + Persistent Text Streaming + gear-allocation rec. 17-20: cron live-pull garnish, polish the WOW first-30-seconds, lock happy path. 20-21: record the 3-min video. The risk is data heterogeneity, contained by caching metros early.
- **Risks:** (1) Public club data is uneven across metros and IG is rate-limited, so the demo MUST run on 1-2 densely cached, hand-verified metros with the live pull as garnish only. (2) The 'unsponsored' inference is heuristic, mitigated by presenting it as a scored guess-with-reasons + confidence, which actually becomes a strength. (3) Theme-fit residual: a hardline enterprise-SaaS-RevOps judge could file 'run club' under consumer/community; mitigated by anchoring the buyer as a brand's grassroots-marketing BUDGET and leaning on the very-current run-club-as-CAC-channel trend (verified: brands are actively shifting spend here). (4) Do NOT touch Strava's API, its 2025/26 agreement explicitly bans AI use of its data and would be a credibility landmine in front of these judges.
- **Why it wins:** It is the highest-EV idea in this domain because it maximizes the three things that actually move this rubric simultaneously: rubric-#1 usefulness is honest, not a reframe (the buyer is a brand's real grassroots-marketing budget, on a verified, surging 2025/26 trend), so it survives a RevOps-purist judge; the signal is genuinely custom and hard-to-buy (rising x unsponsored club momentum, which no vendor sells); and it is a textbook DETECT->ENRICH->SCORE->ACT loop with a visible ACT and explainable, abstaining scores, which is exactly the white space the brief says judges reward. It is also the single best Convex showcase in the set (live re-ranking reactive board, Workpool, Agent, Persistent Text Streaming, cron) which maxes the 20% bonus. It deliberately avoids the two traps that sink its neighbors: no Strava-API dependency (now AI-banned and ToS-hostile) and no individual-runner DMing (AI-SDR backlash). It folds in the cooler-but-fragile Sponsor Whitespace (#13) as a score dimension rather than betting the demo on a rare live event. The merged ClubScout+ClubRadar is strictly stronger than either alone.

**Runner-up:** FinishLine Radar (#7) / Sponsor Radar (#4) tie - FinishLine Radar is the best PURELY-PUBLIC-DATA alternative and the safest data play: marathon results pages are free, recognizable, and 100% public (no ToS minefield), and clustering finishers into orgs (clubs/coaches/corporate teams) then drafting B2B plays is a clean event->enrich->score->act loop with a great 'clusters forming from raw finisher rows' visible-hard-part moment. It is the pick if data-access fear dominates. Sponsor Radar (#4) is the higher-coolness alternative: the double-derivative 'getting fast AND getting popular fast' rising-athlete signal is the most viscerally novel signal in the set and produces an exciting live leaderboard, but it requires wiring TWO data layers (performance + social) in 21h, which is why it is a co-runner-up rather than the winner. ClubRadar beats both on combined theme-fit + Convex-fit + scope safety: it rides the strongest, most current B2B trend (run-club sponsorship spend) with the cleanest live reactive-board demo, while FinishLine wins on data-purity and Sponsor Radar wins on raw coolness.

**Honest verdict:** Honest read: this domain CAN produce a top-3-competitive idea, but it is mildly theme-disadvantaged versus a pure-B2B-SaaS domain and the ceiling is 'strong contender,' not 'lock.' The disadvantage is that 'running' pattern-matches to consumer/fitness in a RevOps-leaning room, so every idea pays a small theme tax. The escape is real and verified: the run-club-as-lowest-CAC-growth-channel trend is genuinely happening in 2025/26 with brand budget moving, which gives the B2B supply-side framings (ClubRadar/ClubScout/FinishLine/Sponsor Radar) an honest, current, judge-recognizable B2B buyer, not a stretch reframe. The cost of the domain is the data layer: Strava is now actively hostile (its 2025/26 API agreement explicitly bans AI use of its data), so any Strava-dependent idea (#1, #5, parts of #6/#11) is effectively disqualified, which is why the winner is built on IG/Eventbrite/luma/RunSignup/race-results instead. Net: a well-executed ClubRadar is a credible top-3 finisher and a strong favorite for the Convex track, but it is not theme-advantaged enough to be a runaway #1 over a best-in-class pure-B2B idea from another domain. Its real edge is that Charlie genuinely cares about this space, which will show up as polish and conviction in the demo, and that is worth real points on Coolness and delivery.

ClubRadar would comfortably crack the LOWER half of the existing top-10 (clearly above Fanatic 51.2, Two-Face 56.6, DriftWatch 62.1, Cut Line 67.5, Keeper 67.4, and competitive with SignalRoom 73.5 / Tripwire 74.1 on the strength of its custom signal + clean DETECT->ENRICH->SCORE->ACT loop + best-in-class Convex showcase). ### Winner: BreakRadar  (EV 0.404 | top-3 32 / Convex 70 / genuine-use 55)
*The A&R deal desk that calls breakouts before the majors do, ranked by an explainable inflection score with an offer drafted and ready.*

BreakRadar is a talent-sourcing deal desk for label A&R, sync agencies, and distributors. It treats independent artists as 'accounts' and a streaming/social velocity inflection as the buying signal. You point it at a genre or a watchlist; it ingests public early-traction time series per track/artist, computes the SECOND derivative (acceleration, not size), corroborates the inflection across 3+ independent sources, and produces a live re-ranking deal board. Each row is an artist climbing the board with an explainable signability score (why now, which sources agree, what the slope looks like), and the ACT is a routed, ranked deal memo plus a drafted DM/email to the artist or manager with the specific evidence ('your save-rate inflected 3 weeks before chart entry; here is the curve'). It abstains and refuses to score when sources disagree or data is thin, which is the trust feature A&R actually needs. The pitch in one line: A&R is a sales pipeline, the inflection is intent, being early by hours is the whole game.

- **Signal:** Composite breakout INFLECTION on public supply-side data: the 2nd derivative (acceleration) of save-rate proxies, playlist-add velocity, TikTok sound-usage growth, Shazam-tag velocity, and Reddit/Discord mention slope per emerging track. The hard-to-buy part is not the raw numbers (tools report levels); it is the slope-of-the-slope detection plus cross-source corroboration that filters one-hit noise from a true inflection. - **DETECT:** Cron/Workpool polls public sources on a loop: YouTube Data API (view/comment velocity per upload), SoundCloud + Bandcamp public pages (play/repost/sales slope), Reddit/Discord public mention counts, and public chart/Shazam-style endpoints where reachable. - **ENRICH:** Resolve the track to the artist, then the artist to a reachable contact (manager email, booking/contact link, socials) via Fiber AI reverse-email/people data plus public press-kit/link-in-bio scraping. Pull a one-paragraph artist context (genre, prior releases, current label status) so the memo is grounded.
- **SCORE:** Per-artist signability score = weighted blend of (a) inflection strength across sources, (b) cross-source agreement count (3+ sources agreeing >> one spiking), (c) recency of the inflection, (d) absolute level still low enough to be unsigned/early. Fully explainable: every score shows the contributing slopes, the agreement count, and a plain-English rationale. Abstains (no score, flagged 'insufficient corroboration') when fewer than 2 sources agree or the series is too short, which is the Danylo-flattering trust move.
- **ACT:** One crisp visible ACT: generate a ranked deal memo for the top artist and a drafted, evidence-specific outreach DM/email to the artist or manager that cites the exact inflection ('your saves-per-listener accelerated starting March 2; majors usually see this 2-3 weeks later').
